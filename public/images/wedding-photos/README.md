# Thư mục ảnh cưới mới cho 2 thiệp (Template 02 & Template 03)

Bạn hãy tải các ảnh cưới mới vào thư mục này:
`public/images/wedding-photos/`

## Gợi ý đặt tên file (tiện lợi và dễ quản lý):
1. **Ảnh bìa / Hero (ảnh mở đầu hoặc ảnh chính):**
   - `hero.jpg` hoặc `hero.webp`

2. **Album ảnh cưới (khoảng 9 - 15 ảnh):**
   - `photo-01.jpg`
   - `photo-02.jpg`
   - `photo-03.jpg`
   - ...
   - Bạn có thể phân biệt nhóm ảnh nếu muốn (ví dụ `ao-trang-01.jpg`, `truyen-thong-01.jpg`).

3. **Ảnh cưới cổng / tư gia / tiệc (nếu có riêng):**
   - `nha-trai.jpg`
   - `nha-gai.jpg`

> Định dạng khuyên dùng: `.webp`, `.jpg`, hoặc `.png`.
