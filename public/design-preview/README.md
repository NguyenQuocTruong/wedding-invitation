# Preview media

All SVG illustrations, envelope motifs and nonfunctional QR artwork in this directory
were authored for this demo. They are not photographs or transferable payment codes.
The three image groups illustrate composition and color only; replace them with
owner-authorized photographs through src/config/preview.ts.
Font files in ../fonts are Google Fonts Lora and Be Vietnam Pro, redistributed with
their SIL Open Font License texts. No external image, font or audio requests are made.
